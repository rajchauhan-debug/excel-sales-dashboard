# Excel Sales Analytics Dashboard

An interactive Excel-based sales analytics dashboard built using Python, Pandas, Plotly and Streamlit.

## Features

- Interactive sales dashboard
- KPI metrics for Total Sales, Total Profit and Total Orders
- Region-wise sales analysis
- Category-wise analysis
- Product performance analysis
- Interactive filters
- Raw sales data display

## Technologies Used

- Python
- Pandas
- Plotly
- Streamlit
- Excel
- Git
- GitHub
